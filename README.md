# Transmute Next.js Website

A Next.js App Router implementation of the Transmute Website Design System & Developer Handoff v1.0.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Routes

- /
- /technology
- /applications
- /applications/mining
- /applications/dredging
- /applications/petroleum
- /applications/water-desalination
- /applications/sanitation-sewage
- /applications/industrial
- /why-transmute
- /about
- /contact
- /resources

## Before production

Replace remote placeholder imagery with approved Transmute product/application photography, validate all engineering claims, connect the contact form to the chosen email/CRM endpoint, and add approved technical documents/logos.
